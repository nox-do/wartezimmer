# Sicherheitsmeldungen für Wartezimmer

Bitte meldet mögliche Sicherheitslücken vertraulich an [info@notaus.de](mailto:info@notaus.de). Ich kümmere mich selbst um die Meldungen.

Eine Meldung sollte die betroffene Version, eine Beschreibung des Problems und Schritte zur Reproduktion mit fiktiven Daten enthalten. Bitte keine Patienteninformationen, Zugangsdaten oder privaten Schlüssel mitsenden.

Sicherheitslücken und vertrauliche Diagnosedaten bitte nicht in öffentlichen GitHub Issues veröffentlichen. Allgemeine technische Fragen und Fehler ohne vertrauliche Inhalte können über die [GitHub Issues](https://github.com/nox-do/wartezimmer/issues) gemeldet werden.
