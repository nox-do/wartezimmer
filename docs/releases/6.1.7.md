# Wartezimmer 6.1.7

Dieses Wartungsrelease korrigiert die gespeicherte HTTPS-IP nach einer Änderung
der Praxisadresse im Manager.

## Änderungen

- Netzwerkeinstellungen und Setup-Assistent übernehmen eine geänderte Praxis-IP
  jetzt auch bei bereits aktiviertem HTTPS in die gespeicherte HTTPS-Konfiguration.
  Bisher konnte dort die alte Adresse stehen bleiben und eine irreführende
  Abweichungswarnung auslösen.
- Der Setup-Assistent schreibt den aktualisierten HTTPS-IP-Wert eindeutig, auch
  wenn das vorhandene Template bereits einen solchen Eintrag enthält.
- Hostnamen, Zertifikatsdaten und die separate Portaladresse bleiben erhalten.
  Externe DNS-Einträge werden nicht automatisch verändert; die Erreichbarkeit
  über den Praxisnamen wird weiterhin gesondert geprüft.

## Installation und Update

**Für diesen Fix den Wartezimmer Manager auf 6.1.7 aktualisieren.** Die Änderung
liegt in dessen eingebettetem Setup. Ein `.pfupdate`-Paket allein aktualisiert
diesen Code nicht. Nach der Manager-Aktualisierung die gewünschte Praxisadresse
unter Netzwerk erneut speichern, falls noch eine alte HTTPS-IP angezeigt wird.

Für den Containerstack das zur Docker-Hostarchitektur passende `.pfupdate`-Paket
verwenden. Die Mindestversion des Managers für das Paketformat bleibt 6.1.3.
Die Downloads enthalten Manager für macOS Apple Silicon, macOS Intel und
Windows x64 sowie Installations- und Updatepakete für Linux ARM64 und AMD64.

Die Manager-Installer bleiben ohne Herausgebersignatur und Apple-Notarisierung.
Prüfsummen stehen in `SHA256SUMS.txt`.

## Bekannte Sicherheitslücke im Manager

**CVE-2026-111497 bleibt im Manager und seinem eingebetteten Setup offen.**
Electron 44.4.3 mit Node 24.21.0 bleibt unverändert. Die Container verwenden
weiterhin Node 22.23.4. Die lokale Setup-API reduziert die Exposition; beim
TLS-Setup bleibt der externe ACME-DNS-Aufruf relevant. Nur vertrauenswürdige
ACME-DNS-Server verwenden. Details stehen in
[KNOWN_VULNERABILITIES.md](https://github.com/nox-do/wartezimmer/blob/v6.1.7/KNOWN_VULNERABILITIES.md).
