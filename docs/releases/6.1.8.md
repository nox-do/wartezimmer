# Wartezimmer 6.1.8 (Entwurf)

Der Wartezimmer Manager wechselt von Electron 44.4.3 auf 44.11.3. Das darin
enthaltene Node 24.22.2 behebt die Brotli-Schwachstelle CVE-2026-111497
im Manager und seinem eingebetteten Setup.

## Update für bestehende Installationen

Sobald das Release verfügbar ist, den neuen Manager auf dem Praxisrechner
installieren. Ein `.pfupdate` aktualisiert nur den Containerstack. Für diesen
Fix ist kein Container-Update erforderlich, wenn App und Sandbox bereits
mit Node 22.23.4 laufen.

## Prüfstand

Im gepackten Manager für macOS auf Apple Silicon wurden Start, Setup-Neustart,
TLS-Zertifikatsprüfung und ein HTTPS-Abruf mit Brotli-Antwort geprüft. Die
Paketprüfung für Intel-Macs und Windows x64 steht aus.
