# Wartezimmer 6.1.8

Dieses Sicherheitsupdate aktualisiert den Wartezimmer Manager von Electron 44.4.3
auf 44.11.3. Die eingebettete Node-Runtime 24.22.2 behebt die Brotli-Schwachstelle
CVE-2026-111497 im Manager und dessen eingebettetem Setup.

## Update für bestehende Installationen

**Für den Sicherheitsfix den neuen Manager auf dem Praxisrechner installieren.**
Ein `.pfupdate` aktualisiert nur den Containerstack und ersetzt den Manager nicht.
App und Sandbox verwenden weiterhin Node 22.23.4; für diesen Fix ist dort kein
zusätzliches Container-Update erforderlich, wenn diese Runtime bereits vorhanden ist.

Die Downloads enthalten Manager für macOS Apple Silicon, macOS Intel und
Windows x64 sowie Erstinstallations- und Updatepakete für Linux ARM64 und AMD64.
Die Mindestversion des Managers für das Paketformat bleibt 6.1.3.

## Prüfstand

- Vollständige lokale Prüfung mit `npm run verify` und `npm run build` bestanden.
- Beide Mac-Pakete auf Architektur, Paketinhalt, Electron 44.11.3, Node 24.22.2,
  SQLite/Brotli sowie Start und Neustart des eingebetteten Setups geprüft.
  Intel-Laufzeittests erfolgten unter Rosetta; der Programmstart wurde auf Apple Silicon geprüft.
- Windows-x64-Installer auf einem Windows-Runner gebaut. Runtime, Setup,
  Installation, Neuinstallation, Deinstallation und Erhalt der Testdaten geprüft.
- Containerimages für beide Architekturen auf Version, Architektur, SQLite und
  Brotli geprüft. Alle vier Archive auf Nutzlast-Prüfsummen und beide Updatepakete
  mit dem offiziellen Importprüfer kontrolliert.

Die Installer bleiben ohne Herausgebersignatur und Apple-Notarisierung.
Prüfsummen stehen in `SHA256SUMS.txt`. Die Netztrennung ist nach der Installation
im konkreten Praxisnetz zu prüfen; eine neue Abnahme auf physischer Intel-Mac-
oder Windows-Hardware war nicht Teil dieses Releases.
